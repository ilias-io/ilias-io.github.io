Detailed Description

template<typename T>
class ilias::TaskGroup< T >

The TaskGroup of tasks, spawn tasks in here and wait for them to finish.

Note
If the group is destroyed, all tasks will receive the stop request. The TaskGroup will not wait for the tasks to finish.
Template Parameters
TThe result type of the tasks.
